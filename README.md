AI Image Classifier
This project is a simple AI image classifier built using Python, Streamlit, and TensorFlow. It allows users to upload an image and uses the MobileNetV2 model to identify what is present in the image.
The application displays the top three predictions along with their confidence scores through a clean and easy-to-use interface. This project helped me understand how pre-trained deep learning models can be integrated into a web application.
Features
Upload JPG and PNG images
Classifies images using the MobileNetV2 model
Displays the top three predictions with confidence scores
Simple and user-friendly interface
Tech Stack
Python
Streamlit
TensorFlow
MobileNetV2
OpenCV
NumPy
Pillow
About
This project was built to explore image classification using deep learning and to gain hands-on experience with deploying AI applications using Streamlit. It demonstrates how a pre-trained model can be used to recognize objects in uploaded images without training a model from scratch.
